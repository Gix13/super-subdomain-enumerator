# Security policy

## Reporting a repository vulnerability

Use GitHub's private vulnerability-reporting or security-advisory feature for vulnerabilities in this repository. Include the affected function or integration, impact, safe reproduction steps, and a minimal proof of concept based on synthetic data or infrastructure you control.

Never attach API keys, cookies, client data, target inventories, HTTP captures, OAST logs, or live vulnerability evidence to a public issue.

## Scope

This policy covers the orchestration code and documented setup in this repository. It does not authorize testing any integrated provider, security tool, or third-party target. This is not a bug-bounty program and no reward is promised.

## Supported version

Only the latest commit on the default branch is supported.
